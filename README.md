# And The Zab

A Vite + React music app with a Node/Express backend.

## Features
- Frontend built with React and Vite
- Express server for API endpoints
- Vercel-ready configuration
- Upload and media handling support

## Getting started

```bash
npm install
npm run dev
```

For production build:

```bash
npm run build
```

## Environment variables

Copy `.env.example` to a new `.env` file and fill in the required values.

## Project structure

- `src/` - React frontend
- `server/` - Express backend
- `api/` - Vercel API entry
- `public/` or static assets - if added later

## Deployment

This project is configured for Vercel-friendly deployment and can also run locally with `npm run dev`.
